# ONE GROUP DOES THE WORK, ON PURPOSE.
#
# This file used to carry named groups for Googlebot, Bingbot, GPTBot,
# ClaudeBot, Google-Extended and CCBot, each containing only "Allow: /".
# Under the robots.txt spec a crawler obeys exactly ONE group -- the most
# specific one matching its token -- and ignores every other group, including
# "*". So each of those groups silently cancelled the whole Disallow list
# below it: Googlebot and Bingbot were free to crawl /app, /admin, /billing
# and /settings, which is the opposite of what the list was written to do.
#
# The rule now lives in a single "*" group so it actually applies to
# everyone. Add a named group only when a crawler genuinely needs different
# rules, and when you do, REPEAT the Disallow list inside it.
#
# There is also no blanket "Allow: /" any more. robots.txt already defaults
# to allow when nothing matches, and the two families of parser disagree on
# precedence: Google takes the LONGEST matching rule, so Disallow: /app
# would win, but a first-match-wins parser takes the Allow purely because it
# is listed first -- cancelling the entire block list. Leaving it out makes
# this file behave identically under both.

User-agent: *
Crawl-delay: 1

# /signup and /login are deliberately NOT disallowed. They were the only CTAs
# reachable from the noscript fallback and the main nav, and blocking them
# broke internal link flow for Googlebot (2026-04-23 audit). Both emit
# <meta robots="noindex,follow"> via <SEO noindex>, so they are crawled for
# link equity but stay out of SERPs.
#
# WHO THIS ALLOWS. Every crawler below is permitted over all public pages by
# the group above. They are documented as comments rather than as named groups
# on purpose: a named group would REPLACE this one for that crawler and hand
# it the authenticated app -- the bug described at the top of this file.
#
#   Search        Googlebot, Bingbot, DuckDuckBot, Slurp, Applebot
#   AI search     OAI-SearchBot (ChatGPT Search), ChatGPT-User, PerplexityBot,
#                 Perplexity-User, Claude-SearchBot, Claude-User, Amazonbot,
#                 and Bingbot again for Microsoft Copilot
#   AI training   GPTBot, ClaudeBot, Google-Extended, Applebot-Extended
#
# OAI-SearchBot surfaces pages in ChatGPT Search; GPTBot is the model training
# crawler. Separate tokens, separate concerns -- a change to one is not a
# change to the other.
#
# TRAINING POLICY: this site currently permits AI training crawlers. That is a
# deliberate owner choice and is unchanged here. To opt out of training WITHOUT
# losing AI-search visibility, add groups for GPTBot / ClaudeBot /
# Google-Extended / Applebot-Extended with "Disallow: /", each repeating the
# block list above, and leave OAI-SearchBot, Claude-SearchBot and
# PerplexityBot alone.
